# «Медикаменте» — проектная работа, спринт 10

Архитектурное решение для медицинской компании: защита персональных и медицинских данных, самостоятельная запись пациентов, аналитика и переход от ручной работы с Excel и сканами к единой платформе. Бухгалтерский, кадровый и складской учёт сохраняется в 1С. Решение учитывает открытие филиалов и пятикратный рост объёма данных.

**Стадия: архитектурное проектирование.**

## Общие решения

- **MVP через два месяца:** порталы пациента и ресепшена, реестр пациентов, единое расписание, договоры и учёт оснований обработки. Ресепшен напоминает о приёме пациенту и врачу за сутки. Основа — модульное Java-приложение, PostgreSQL и приватное хранилище документов.
- **Развитие за год:** медицинские документы, лабораторная интеграция, онлайн-оплата, мобильное приложение, автоматические уведомления и аналитика. Функции вводятся отдельными волнами с проверкой данных и прав доступа.
- **Защита:** права проверяются по роли, цели, филиалу и принадлежности данных пациенту. Используются шифрование, разделение ключей и данных, минимизация передаваемых сведений и аудит. Метки хранятся в каталоге и учитываются при проверке доступа в сервисах и хранилищах.
- **Аналитика:** файлы проходят классификацию и проверку перед публикацией. Персональные данные остаются в закрытом слое; аналитик получает проверенные сводные показатели через сервис чтения. Неопределённый класс блокирует публикацию до разбора.
- **Миграция:** Parallel Run с поэтапной передачей данных. Изменять каждый объект в любой момент может только одна система. Для переключения предусмотрены сверка, возврат с сохранением новых операций и восстановление при сбое.
